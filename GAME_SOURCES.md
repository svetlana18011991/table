# Игровые механики

В проект встроены три присланных пользователем механики: «Учебная гонка», «Башня» и «Пиньята». Генератор передаёт в них вопросы по таблице умножения и создаёт автономный HTML-файл. Локальные графические файлы заменены встроенными SVG-изображениями, чтобы ученику не требовалась папка assets.
