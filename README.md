# Тренажёр по таблице умножения — версия для GitHub Pages

Эта версия специально разделена на небольшие файлы, чтобы её можно было загрузить через сайт GitHub.

## Важно

Не загружайте ZIP-файл в репозиторий. Сначала распакуйте архив, затем загрузите **содержимое папки**:

- `index.html`
- `styles.css`
- `app.js`
- папку `game-data`

Все отдельные файлы меньше ограничения браузерной загрузки GitHub.

## Публикация

1. Распакуйте архив.
2. На странице репозитория нажмите **Add file → Upload files**.
3. Перетащите все файлы и папку `game-data`.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.
7. Нажмите **Save**.

## Автономные файлы

На опубликованном сайте кнопка «Скачать HTML» собирает один автономный файл со стилями, кодом и Base64-изображениями. Кнопка «Создать игру» также скачивает готовую автономную игру.

Сам репозиторий хранит Base64-ресурсы раздельно только для того, чтобы GitHub принимал их через браузер.

## Исправление оригинальной гонки

Генератор гонки использует исходную механику версии 34.18, штатное шоссе, зелёный парк, шесть оригинальных машин игрока и семь оригинальных участников движения. При создании HTML браузер пытается получить изображения из опубликованной исходной гонки по адресу `/gonka/` и встроить их в скачиваемый файл как Base64.

Если браузер не разрешит преобразовать изображения в Base64, игра всё равно будет создана с оригинальным визуалом через интернет-ссылки. В таком случае для отображения машин и окружения ученику понадобится интернет.

## Запуск и скачивание

После настройки доступны два независимых действия:

- **«Начать здесь»** — запускает тренировку сразу в текущем окне;
- **«Скачать ученику (.html)»** — скачивает готовый автономный файл и не переключает текущую страницу.

Когда ученик открывает скачанный HTML, тренировка запускается автоматически. После завершения кнопка «Новая тренировка» повторяет то же задание без возврата к учительским настройкам.
