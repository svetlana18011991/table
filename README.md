# Тренажёр по таблице умножения — один файл

Загрузите в корень репозитория только `index.html`.

Внутри уже находятся:

- пароль `счет` / `счёт`;
- выбор таблиц;
- запуск и скачивание ученического тренажёра;
- гонка, башня и пиньята;
- игровые изображения в Base64;
- стили и JavaScript.

Перед загрузкой удалите старые `index.html`, `app.js`, `styles.css`, `assets.js`, `templates.js` и папку `game-data`, чтобы не смешивать версии.
