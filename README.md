# Тренажёр по таблице умножения

Готовый статический веб-тренажёр для учителя и ученика. Работает без сервера и может быть опубликован через GitHub Pages.

## Возможности

- выбор одной или нескольких таблиц;
- случайные таблицы от 2 до 10;
- настройка количества примеров;
- диапазон множителей от 1 до 12;
- общий таймер;
- разные типы заданий:
  - обычный пример;
  - перестановка множителей;
  - пропущенный множитель;
  - деление;
  - выбор ответа;
  - верно или неверно;
  - сравнение выражений;
  - наглядная модель;
- вторая попытка;
- мгновенная обратная связь;
- итоговая статистика;
- результаты по отдельным таблицам;
- работа над ошибками;
- экспорт результатов в CSV;
- сохранение последних результатов в браузере;
- светлая и тёмная темы.

## Запуск на компьютере

Откройте файл `index.html` двойным щелчком.

Для разработки удобнее использовать расширение Live Server в Visual Studio Code.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него все файлы проекта.
3. Откройте `Settings`.
4. Перейдите в раздел `Pages`.
5. В блоке `Build and deployment` выберите:
   - Source: `Deploy from a branch`;
   - Branch: `main`;
   - Folder: `/ (root)`.
6. Нажмите `Save`.
7. Через некоторое время GitHub покажет адрес опубликованного сайта.

## Команды Git

```bash
git init

git commit -m "Первый релиз тренажёра"
```

## Где менять настройки

Основная логика находится в `app.js`.

Диапазон таблиц задаётся в функции `buildTableControls()`:

```js
for (let table = 2; table <= 10; table += 1)
```

Максимальный диапазон множителей задаётся в `index.html`:

```html
<input id="maxFactor" type="number" min="1" max="12" value="10" />
```

## Хранение результатов

История сохраняется только на текущем устройстве в `localStorage`. Для общей учительской панели, аккаунтов учеников и синхронизации между устройствами понадобится сервер или облачная база данных, например Firebase или Supabase.
