# Тренажёр по таблице умножения — облегчённая версия для GitHub Pages

Эта сборка специально уменьшена для загрузки через сайт GitHub. Оригинальные изображения «Башни» и «Пиньяты» преобразованы в WebP и хранятся в компактном Base64.

## Файлы

- `index.html`
- `styles.css`
- `app.js`
- `assets.js`
- `templates.js`
- `README.md`

Папок и крупных файлов нет. Самый большой файл заметно меньше лимита GitHub.

## Как загрузить

1. Распакуйте ZIP.
2. Откройте репозиторий GitHub.
3. Нажмите **Add file → Upload files**.
4. Перетащите все файлы из распакованной папки.
5. Нажмите **Commit changes**.
6. В **Settings → Pages** выберите ветку `main` и папку `/ (root)`.

Не загружайте ZIP вместо распакованных файлов.

## Возможности

- начать тренировку прямо на странице;
- скачать отдельный автономный HTML для ученика;
- создать гонку, башню или пиньяту;
- башня содержит 9 заданий;
- пиньята содержит 5 заданий;
- пароль: `счет` или `счёт`, регистр не учитывается;
- ученический HTML после пароля запускает тренировку автоматически.

## Размер

Общий размер распакованного проекта: около 2.7 МБ.
